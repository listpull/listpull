    Why no API key field?

    Security is part of the product.

    The Neubra Electron application uses a desktop preload bridge for model calls. A public GitHub Pages site has no trusted server, so requesting visitors' private OpenAI or other provider API keys directly would expose secret credentials to client-side JavaScript and browser tooling. We intentionally do not collect keys here. Instead, compatible browsers can opt into WebGPU-based local model inference above. A production hosted version still needs a separately deployed, authenticated, rate-limited backend.

    This demo proves the retrieval, source attribution, context construction, and human-readable interaction pattern. The optional WebGPU section can execute a model locally once installed. Neither mode searches private documents or guarantees accuracy.
