    Why no API key field?

    Security is part of the product.

    The Neubra Electron application uses a desktop preload bridge for model calls. A public GitHub Pages site has no trusted server, so requesting visitors' private OpenAI or other provider API keys directly would expose secret credentials to client-side JavaScript and browser tooling. We intentionally do not collect keys here. A production version should use a separately deployed, authenticated, rate-limited backend or a user's own trusted proxy.

    This demo proves the retrieval, source attribution, context construction, and human-readable interaction pattern. It does not claim to execute a large language model, search private documents, or guarantee accuracy.
