Creative Studio: browser-based media workflows.

02 / AI + development

AI Agent & live coding workspace.

The challenge: feedback is more useful when people can see and test the software they are discussing. What we built: a browser code workspace for HTML, CSS and JavaScript, with live preview and an optional AI assistant on compatible devices.
